# Security policy

This repository contains public data and local build tooling; it does not intentionally contain credentials or production integrations.

For schema bugs, broken links, and ordinary data corrections, open a public issue. For a vulnerability, exposed secret, malicious link, private personal information, or another sensitive report, use private vulnerability reporting on the repository's GitHub Security page. Do not include sensitive details in a public issue.

If a credential is accidentally committed, treat it as compromised and rotate it immediately. Removing it from Git history is not sufficient on its own.
